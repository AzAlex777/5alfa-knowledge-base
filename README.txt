База знаний 5 Alfa

Восстановленная статическая версия из архива Claude Artifact.

Для открытия локально откройте index.html в браузере. Для публикации загрузите всё содержимое этой папки на статический веб-хостинг, сохраняя структуру файлов. После публикации можно раздать менеджерам ссылку на index.html.

Изображения, видео и данные расписания находятся рядом с index.html. Шрифты и ссылки на Google Drive/Google Sheets загружаются из внешних сервисов.
